# Antigravity Cognitive Skills Catalog

This directory contains specialized cognitive frameworks and operational skills for Antigravity agents. Each skill follows Google Antigravity official specifications with native English, progressive disclosure, and concise execution steps.

## Available Skills

| Skill Command | Purpose & Trigger |
| :--- | :--- |
| `/mece-decomposition` | Deconstruct complex, ambiguous problems into Mutually Exclusive, Collectively Exhaustive sub-problems. |
| `/first-principles` | Deconstruct assumptions down to fundamental truths and rebuild solutions from foundational axioms. |
| `/systems-thinking` | Analyze recurring issues using feedback loops, stocks, flows, and high-leverage intervention points. |
| `/probabilistic-thinking` | Evaluate high-uncertainty decisions using base rates, expected values, and Bayesian updates. |
| `/deep-analysis` | Execute a multi-stage analytical pipeline combining MECE, First Principles, Systems, and Probability. |
| `/quality-review` | Audit deliverables before final output against correctness, minimal edits, and simplicity criteria. |
| `/tech-doc` | Write structured, concise technical design documents, architectural proposals, and plans. |
| `/code-style` | Apply software craftsmanship, minimal mutation, and clean code guidelines. |
