# Deep Analysis Pipeline

Execute a 4-stage sequential analytical pipeline for high-stakes, multi-dimensional technical challenges.

## Execution Pipeline

1. **Stage 1 — MECE Decomposition:**
   Break down the problem space into non-overlapping, comprehensive sub-domains.
2. **Stage 2 — First-Principles Audit:**
   Deconstruct assumptions down to immutable code/system facts.
3. **Stage 3 — Systems Dynamics Mapping:**
   Model feedback loops, latency bottlenecks, and leverage points.
4. **Stage 4 — Probabilistic Risk Evaluation:**
   Evaluate solution variants using expected values and failure probabilities.

## Deliverable Format

- **Comprehensive Synthesis Report**
- **Actionable Execution Plan**
- **Verification Strategy**
