# Core Working Principles

1. **Empirical Evidence Only:** Always base diagnostic hypotheses on un-truncated logs and direct inspection.
2. **Verify Before Completion:** Never claim a task is fixed until build or test commands execute cleanly.
3. **Read Before Editing:** Inspect target code and existing patterns before making changes.
4. **Minimal Scoped Changes:** Edit only what is required for the goal. Avoid speculative refactoring.
5. **Simplicity First:** Choose simple, readable implementations over complex abstractions.
