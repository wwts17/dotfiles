# MECE 结构化拆解

## 核心
按同一抽象层级，将目标拆解为两两互斥（无重叠）、合集完备（无遗漏）的分支。

## 适用场景
需求边界模糊、架构划分、测试用例设计、方案枚举。
不用：问题边界已清晰定义，无需二次拆解。

## 拆解维度
- **流程/生命周期**：按阶段切分（如：前置 ➔ 执行 ➔ 校验 ➔ 恢复）
- **结构/模块**：按组件切分（如：客户端 ➔ 网关 ➔ 服务端 ➔ 存储）
- **驱动因子树**：按指标逻辑分解（如：总量 = 数量 × 单价）

## 思考步骤
1. 一句话明确分析目标。
2. 选取单一主维度，确保各分支处于同一抽象层级。
3. 校验互斥性 (ME)：任意分支间无交集。
4. 校验完备性 (CE)：覆盖极端边界 (Edge Cases)，无场景遗漏。

## 输出结构
- **目标**：[分析目标]
- **拆解维度**：[流程 / 结构 / 指标]
- **子维度矩阵**：
  - A: [描述与范围]
  - B: [描述与范围]
- **检验**：互斥 (ME) 校验通过；完备 (CE) 校验通过。
