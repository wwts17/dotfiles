# 系统思考与因果回路分析

## 核心
摒弃单点线性因果。在系统结构层识别存量、流量与反馈环，通过改变系统规则或反馈结构解决反复发作的问题。

## 适用场景
故障反复发作、多模块非线性交互引发的问题、寻找高杠杆干预点。
不用：无状态累积的单点函数/简单逻辑调试。

## 思考步骤
1. **识别存量 (Stock)**：找出随时间累积的关键状态（如：队列积压、内存占用）。
2. **映射流量 (Flow)**：确定改变存量的流入与流出速率。
3. **分析反馈环**：识别加剧失衡的增强回路 (R+) 与维持稳定的调节回路 (B-)。
4. **定位杠杆点**：依据“参数调节 < 流量缓冲 < 反馈结构 < 系统规则”寻找最高效干预点。

## 输出结构
- **核心存量 (Stock)**：[累积指标]
- **流入/流出量 (Flow)**：流入 [速率A] / 流出 [速率B]
- **反馈回路 (Loops)**：[增强回路 R+ / 调节回路 B-]
- **高杠杆方案**：[改变系统规则或引入负反馈回路的干预措施]
