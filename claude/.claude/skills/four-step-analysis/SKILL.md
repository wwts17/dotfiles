# 四步深度分析

## 核心
按序串联四大思维工具，前一步产出递进作为下一步输入：
`MECE 拆解` ➔ `第一性原理` ➔ `系统思考` ➔ `概率决策`

## 适用场景
重大架构重构、复杂技术选型、重大事故根因分析等高风险、无既定经验可循的问题。
不用：例行简单任务，单工具即满足需求。

## 思考步骤
1. **MECE 拆解** (`mece-decomposition`)：将问题解构为无重叠、无遗漏的正交子维度。
2. **第一性原理** (`first-principles`)：剥离惯性假设，归约至物理/工程硬约束。
3. **系统思考** (`systems-thinking`)：分析存量流量与反馈回路，定位高杠杆干预点。
4. **概率决策** (`probabilistic-thinking`)：计算方案期望效用，设定量化观测与熔断条件。

## 输出结构
- **1. MECE 子维度**：[正交分支 A / B / C]
- **2. 基础事实**：[剥离假设后的硬约束]
- **3. 系统杠杆点**：[关键反馈回路与干预节点]
- **4. 决策与预案**：[最优方案 (EV) + 观测熔断阈值]
