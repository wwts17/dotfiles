# 第一性原理推演

## 核心
拒绝基于惯例或类比的盲目继承。解构现有方案的隐性假设，归约至基础事实，自底向上重新推演最优解。

## 适用场景
突破历史遗留架构限制、评估技术路线差异巨大的方案。
不用：例行增量开发、已有标准成熟且满意的场景。

## 思考步骤
1. 列出当前被普遍接受的结论或惯性方案。
2. 逐一识别该方案依赖的隐性假设（技术、成本、流程）。
3. 追问假设依据，剔除人为规则，归约至物理/工程硬约束。
4. 仅基于硬约束，自底向上重新推导最佳架构/设计。

## 输出结构
- **现存方案/惯例**：[待质疑的结论]
- **隐性假设解构**：[假设 1]（已失效/非硬约束）；[假设 2]（有效）
- **基础事实 (Axioms)**：[不可逾越的物理/工程硬约束]
- **重建方案**：[自底向上推导出的最佳设计与优化空间]
